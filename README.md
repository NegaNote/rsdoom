# RSDoom: A Port of the Doom Engine to Rust

Currently, it's very barebones, but the eventual goal is to have a full doom engine written in safe and idiomatic Rust.

Ships with Freedoom assets (freedoom1.wad and freedoom2.wad), but you can also use your own WAD files.

Freedoom is MIT licensed, so you can use it freely.
License document for Freedoom is at [COPYING-FREEDOOM.adoc](COPYING-FREEDOOM.adoc).
You can also use the original Doom WAD files if you own them.

Current goal is just to get the engine running at all, then to make it actually feel like Doom.
Eventually may harden to full compatibility with demos.
